Windows

Download for Windows (.zip)
Windows 10 or 11, 64-bit. Unzip, then open INSTALL.txt.

First launch on a Mac

The apps aren't signed with an Apple developer certificate yet, so macOS asks for one confirmation. Drag the apps into Applications, then right-click an app → Open → Open. Or run this once in Terminal:

xattr -dr com.apple.quarantine "/Applications/GPUSA Admin.app"
xattr -dr com.apple.quarantine "/Applications/GPUSA POS.app"
xattr -dr com.apple.quarantine "/Applications/GPUSA Depot.app"
First launch on Windows

If Windows says "Windows protected your PC", click More info → Run anyway (the apps aren't code-signed yet).

Where do I start?

Open Admin first. On a new system it asks you to create the first administrator. After that, open POS at a till and Depot in the warehouse. All three on one computer share one database automatically.
